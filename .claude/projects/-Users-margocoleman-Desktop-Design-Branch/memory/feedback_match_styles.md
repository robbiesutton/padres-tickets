---
name: Match styles consistently across all instances
description: When adding or updating a UI element, ensure ALL similar elements on the same page and across related pages match in size, color, and weight
type: feedback
---

When changing or adding a styled element (button, link, icon), always check and update ALL matching elements on the same page and related pages to use identical styles. Don't leave mismatches.

**Why:** User has been frustrated multiple times by inconsistent styling between paired elements (e.g., Back and Sign out buttons having different text sizes, colors, icon sizes). These small mismatches are noticeable and feel sloppy.

**How to apply:** Before finishing any style change, audit the page for sibling/paired elements and ensure they share the same text size, color, font weight, and icon dimensions. Don't just update one side of a pair.
